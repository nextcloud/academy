## How ExApp frontend API calls work

In a PHP Nextcloud app, you use `@nextcloud/axios` because it automatically attaches the `requesttoken` CSRF header that Nextcloud requires for state-changing requests.

**ExApps don't need this.** When your Vue code makes an API call, it goes through the AppAPI proxy at `/apps/app_api/proxy/pinboard_python/...`. AppAPI handles authentication at the proxy level using the session cookie of the logged-in user — it validates who the user is and passes that information to your FastAPI server via the `AUTHORIZATION-APP-API` header. Your Vue code just uses plain `axios`.

```js
// ✅ ExApp — plain axios through the AppAPI proxy
import axios from 'axios'
import { generateUrl } from '@nextcloud/router'
import { APP_API_PROXY_URL_PREFIX, EX_APP_ID } from './constants/AppAPI.js'

await axios.get(generateUrl(`${APP_API_PROXY_URL_PREFIX}/${EX_APP_ID}/pins`))

// ❌ Not needed for ExApps — @nextcloud/axios is for PHP apps
import axios from '@nextcloud/axios'
```

Everything else — `NcAppContent`, `NcEmptyContent`, `NcButton`, `NcModal`, `NcTextField`, CSS variables, `@nextcloud/dialogs` for toasts — is identical to a standard Nextcloud Vue app.

## Step 1: Skeleton and data fetching

Replace `src/App.vue` with the full component skeleton. This establishes the structure that Steps 2 and 3 build on, and makes the first API call as soon as the component mounts.

```vue
<!--
  SPDX-FileCopyrightText: 2025 Your Name
  SPDX-License-Identifier: AGPL-3.0-or-later
-->
<template>
  <NcAppContent>
    <div class="pinboard">
      <h2>{{ t('pinboard_python', 'Your pins') }}</h2>
    </div>
  </NcAppContent>
</template>

<script>
import axios from 'axios'
import { generateUrl } from '@nextcloud/router'
import { translate as t } from '@nextcloud/l10n'
import { NcAppContent } from '@nextcloud/vue'
import { APP_API_PROXY_URL_PREFIX, EX_APP_ID } from './constants/AppAPI.js'

export default {
  name: 'App',
  components: { NcAppContent },

  data() {
    return {
      pins: [],
      loading: false,
    }
  },

  mounted() {
    this.fetchPins()
  },

  methods: {
    async fetchPins() {
      this.loading = true
      try {
        const response = await axios.get(
          generateUrl(`${APP_API_PROXY_URL_PREFIX}/${EX_APP_ID}/pins`)
        )
        this.pins = response.data
      } catch (error) {
        console.error('Failed to fetch pins', error)
      } finally {
        this.loading = false
      }
    },
  },
}
</script>

<style scoped>
.pinboard {
  padding: 20px;
  max-width: 800px;
}
</style>
```

**`NcAppContent`** — always the outermost wrapper in a Nextcloud app page. Handles margins, scroll behaviour, and integration with the Nextcloud frame.

**`generateUrl(`${APP_API_PROXY_URL_PREFIX}/${EX_APP_ID}/pins`)`** — builds the full proxy URL: `/apps/app_api/proxy/pinboard_python/pins`. This routes through AppAPI to your FastAPI server. Never hardcode this path.

**`mounted()`** — kicks off the fetch after the component is inserted into the DOM. This is equivalent to PHP M6's same pattern.

## Step 2: Display pins

Add the three rendering states — loading, has pins, empty — and the CSS to style them. Update the `<template>`, `components`, and `<style scoped>` sections:

</template>

**CSS variables** — `var(--color-border)`, `var(--color-main-text)`, `var(--color-text-maxcontrast)` are defined by Nextcloud's theming system. They switch automatically for light/dark mode and inherit custom brand colours set by administrators. Always use them instead of hardcoded colours.

**`NcEmptyContent`** — the standard Nextcloud empty state component. Use it instead of writing custom "nothing here" text — it matches the design language of the rest of Nextcloud.

## Step 3: The Add pin form

Add the button that opens a modal with the create pin form. Introduces `NcButton`, `NcModal`, and `NcTextField`, plus the `showSuccess`/`showError` toast notifications:

```vue
<!-- Add to template (replace h2 with this header): -->
<div class="pinboard__header">
  <h2>{{ t('pinboard_python', 'Your pins') }}</h2>
  <NcButton type="primary" @click="showAddForm = true">
    <template #icon><PlusIcon :size="20" /></template>
    {{ t('pinboard_python', 'Add pin') }}
  </NcButton>
</div>

<NcModal v-if="showAddForm" @close="showAddForm = false">
  <template #default>
    <div class="pinboard__add-form">
      <h3>{{ t('pinboard_python', 'Add a new pin') }}</h3>
      <NcTextField
        :label="t('pinboard_python', 'URL')"
        :value.sync="newPin.url"
        :error="!!urlError"
        :helper-text="urlError"
        @keydown.enter="createPin"
      />
      <NcTextField
        :label="t('pinboard_python', 'Title (optional)')"
        :value.sync="newPin.title"
        @keydown.enter="createPin"
      />
      <div class="pinboard__add-form__actions">
        <NcButton @click="showAddForm = false">
          {{ t('pinboard_python', 'Cancel') }}
        </NcButton>
        <NcButton type="primary" :disabled="loading" @click="createPin">
          {{ t('pinboard_python', 'Save') }}
        </NcButton>
      </div>
    </div>
  </template>
</NcModal>

<script>
// Add to imports:
import axios from 'axios'
import { showError, showSuccess } from '@nextcloud/dialogs'
import '@nextcloud/dialogs/style.css'
import { NcButton, NcModal, NcTextField } from '@nextcloud/vue'
import PlusIcon from 'vue-material-design-icons/Plus.vue'

// Add to data():
// showAddForm: false,
// newPin: { url: '', title: '' },
// urlError: '',

// Add to methods:
async createPin() {
  this.urlError = ''
  if (!this.newPin.url.trim()) {
    this.urlError = t('pinboard_python', 'URL is required')
    return
  }
  this.loading = true
  try {
    const response = await axios.post(
      generateUrl(`${APP_API_PROXY_URL_PREFIX}/${EX_APP_ID}/pins`),
      {
        url: this.newPin.url.trim(),
        title: this.newPin.title.trim() || null,
      }
    )
    this.pins.unshift(response.data)
    this.newPin = { url: '', title: '' }
    this.showAddForm = false
    showSuccess(t('pinboard_python', 'Pin saved'))
  } catch (error) {
    console.error('Failed to create pin', error)
    showError(t('pinboard_python', 'Failed to save pin'))
  } finally {
    this.loading = false
  }
},
</script>

<style scoped>
.pinboard__header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  margin-bottom: 20px;
}
.pinboard__add-form {
  padding: 20px;
  display: flex;
  flex-direction: column;
  gap: 16px;
  min-width: 360px;
}
.pinboard__add-form__actions {
  display: flex;
  justify-content: flex-end;
  gap: 8px;
}
</style>
```

**`pins.unshift(response.data)`** — the optimistic update pattern. Adds the new pin to the front of the list immediately using the object the server just returned. No second API call needed — the data is already in sync.

**`import '@nextcloud/dialogs/style.css'`** — required or toasts render unstyled. Import it once, in this component or in `main.js`.

**`v-if` on `NcModal`** — use `v-if` not `v-show`. This fully removes the modal from the DOM when closed, which resets the form fields and avoids focus trapping issues.

## Common problems

**API calls return 401**  
You're not logged in to Nextcloud in that browser session, or the session expired. Log in again at `http://nextcloud.local`.

**API calls return 404**  
The app may not be registered. Run `./scripts/occ.sh nextcloud -- app_api:app:list` from `~/nextcloud-docker-dev/` and check `pinboard_python` is listed and enabled.

**Pins don't appear after adding**  
Check that `response.data` in `createPin` returns the full pin object with `id`, `url`, etc. If your FastAPI endpoint returns something unexpected, `pins.unshift()` may still work but render oddly.

**Toasts show unstyled**  
`import '@nextcloud/dialogs/style.css'` is missing. Add it to `App.vue` or `main.js`.

**Modal doesn't reset form fields when reopened**  
You're using `v-show` instead of `v-if` on `NcModal`. Change to `v-if` so the modal is fully destroyed and recreated on each open.
